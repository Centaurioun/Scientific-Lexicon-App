## Findings and dispositions
- R20 ahocorasick 1.0.2: 13/13 parity fixtures; scan 1.365 ms vs oracle 521.840 ms at 100k keys; build 1895.703 ms, heap delta 46,194,088 B. The timed oracle sorts while timed R20 output does not; parity is separately checked using sorted outputs. Therefore ~382x is an indicative scan comparison, not a fair end-to-end speed guarantee. Re-run equivalent output grouping/sorting, repeated build and worker/rebuild costs in target app. 10-key oracle faster in this specific run. Use R20 as preferred optional indexed matcher behind port; no performance promise. R21 1.0.1 missing declared index.js; HOLD; 1.2.0 untested, no need to retest now.
- Wink 2.4.0 and model 1.8.1: actual Node and Brave execution; 25 reconstructed tokens; six labeled spans, 23 predictions (6 TP,17 extra under fixture labels; P=.261 R=1). Simple grammar 3/6, 14 predictions. Synthetic fixture used for grammar design, not independent holdout. Probe accesses internal its.js path; use public supported API in production. Browser bundle 3.5 MiB minified, ~1 MB gzip; memory single observation. Select feature adapter, not scientific NER. Expand labeled corpus and ranking later.
- IndexedDB native and Dexie 4.4.7: valid evidence of basic browser feasibility; not complete repository validation. Native probe apply catches unexpected transaction errors and can return its previous success-like result; fail closed and report actual errors in product. Some checks conditionally log PASS without throwing on failure; invalid-backup check observes only concept rows and does not assert rejection explicitly. es.put can overwrite an existing expression ID; verified update path is a separate simplified guard, not coverage of all writes. Snapshot uses per-store reads rather than one consistent read transaction. Restore uses put and minimal validation; clean target only, no proof of safe overwrite/rollback on existing data. Dexie specifically tested commit and rollback only; other checks are native. These are limitations of a synthetic probe, not defects in the external library. Actual domain tests must use hard assertions and check all affected stores.
- Persistence grant false; normal access worked. No quota/denial/restart or simultaneous multi-tab race, realistic migration. Browser version absent. Never use preview origin for irreplaceable data; portable backup first.
- Registry SRI values recorded, package metadata and selected license evidence; combined 571-node graph includes failed R21 test/build dependencies. Do not infer selected dependency graph is that large. Verify selected-only lock, integrity, transitive licenses/NOTICE and advisory review before integration; no project-wide license assigned.
- AI Studio account/runtime not opened. Documentation-level compatibility only. Authorize synthetic stage-0 probe in actual account; if Next.js unsupported use documented export route or reconsider host while retaining domain ports.
