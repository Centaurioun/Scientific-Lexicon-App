## Intent and scope
Extend the working WP01 English extraction and EN/TR terminology library with scientific candidate quality, document ingestion, ranking, dictionary-pack staging/lookup and evaluation. Preserve the current core and data contract. No new application repo, no S3 bulk import, S4 enrichment/AI, phrasebank, Turkish NLP, cloud services or real private data. S2 is not a guarantee of G5 scientific accuracy or G4 readiness.

## Alternatives
A: integrate JATE/PyATE/TermSuite Python engines, biomedical models and corpora into app now — reject: added runtime, privacy, duplicated pipeline, unqualified rights and dependencies. B: extend existing TypeScript ports with one transparent pure statistical comparator, local structured input and session-only hints; qualify new parsers separately and preserve S1 baseline — selected for the bounded handoff. C: only improve UX and postpone scientific evaluation — reject as incomplete for approved S2. Python JATE v3 remains primary offline reference, PyATE secondary, TermSuite reference only; no new runtime or wholesale upstream code acquisition.

## Six-cycle review
1. Intent: approved baseline §§5,8,9,13 explicitly targets S2 scientific quality + MD/DOCX + dictionary packs/benchmark + improved lookup. One large package, 12 sequential tasks with internal checkpoints; independent tasks continue around environment blockers.
2. Architecture: preserve canonical S1 schema/ChangeSet/Dexie and exact spans. New parser representation, candidate evidence, rank and packs are session-only projections. No migration or hidden persistence. Markdown offsets refer to immutable analyzed text; DOCX extracted text not binary offsets; explicitly disclose omissions. Existing retained records/backups remain valid.
3. Evidence/reuse: WP01 G3 synthetic PASS and prior G1/G2; R12/R09 are static references, not tested dependencies. Use existing qualified Wink/R20, Zod/Vitest/Playwright. Reference prior source dossiers rather than rediscover. C-value selected as experimental transparent comparator with documented formula and single-word handling; NC-value and contrast methods conditional on actual evidence, not arbitrary weights.
4. Integrity: G4 remains NOT READY; no actual personal or external corpus intake. G5 requires independently annotated rights-cleared EN holdout, threshold approval after baseline. Dictionary packs synthetic read-only hints, no master auto writes; source rights gate. DOCX external entities, archive bombs, remote links, unsupported structures must be addressed before enablement. Bounded shared span tracker, cancellation, stale proposals, no silent truncation. No change to lock without G1.
5. Efficiency: 12 tasks in one AI Studio prompt, retain current dev launcher, canonical npm lock, known Bun/Playwright limits; Codex verifies integrated result, not each small change. Do not stop independent work due to blocked DOCX or unavailable licensed benchmarks. No fabricated elapsed time or completion claim.
6. Challenge: source coordinate system, ranking versus verification, same-span homonyms, repeated/nested terms, empty gold metrics, wrong source permissions, worker fallback and actual limits checked in self-review; D2/D3/D4/D5/D6/D7/D8/D10/D11 tests target these. G3 regression is separate from G5. No independent builder agent available here; self-review only. Material semantic/security/host changes still require owner approval.
